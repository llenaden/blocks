# MyBlocks

3D-конструктор из кубиков прямо в браузере: свободная сборка из всех деталей, сборка готовых моделей по 3D-инструкции, загрузка своих моделей из BrickLink Studio (.io) и LDraw (.ldr, .mpd), свои наборы деталей из списков BrickLink (.xml) и Rebrickable (.csv).

Приложение — один файл `index.html`, без сервера и без установки. Все постройки, загруженные модели и наборы хранятся только на устройстве (в браузере).

## Как запустить

- **Онлайн:** включите GitHub Pages для репозитория (Settings → Pages → Deploy from a branch → `main`, папка `/`). Приложение откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
- **Локально:** откройте `index.html` в браузере (нужен интернет: библиотеки three.js и pako загружаются с cdnjs).

## Что внутри

- Готовые модели: собственные модели проекта (дворец, мельница, павильон, камин, колодец).
- Каталог деталей с формами и правилами соединения.
- Встроенных официальных наборов LEGO нет: свои наборы и модели других авторов каждый загружает сам кнопками «Загрузить набор» и «Загрузить модель». Модели других авторов используйте по их лицензии.
